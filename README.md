# Sakinah: releases

Signed Android builds of Sakinah, and the `update.json` file the app reads to find a new version.
The application source code is not in this repository.

Versions Android de Sakinah signées, et fichier `update.json` que l'application lit pour trouver une nouvelle version.
Le code source de l'application n'est pas dans ce dépôt.

## Download / Télécharger

Website / Site : https://obiodev.github.io/sakina-releases/

Latest version / Dernière version: https://raw.githubusercontent.com/obiodev/sakina-releases/main/sakinah.apk

## Versions

- `sakinah.apk` and `sakinah-1.6.0.apk`: version 1.6.0, package `com.motoko.sakinah`, the same app as on Google Play.
- `update.json` and `sakinah-1.5.1.apk`: kept for installs of the former package `com.sakinah.app`, so that they are not offered a second app.
